KALKULASI STUDIO — WEBSITE MULTI-HALAMAN

Isi folder:
- index.html                 : Kalkulasi baru
- spesifikasi_produk.html    : Spesifikasi produk
- proses_produksi.html       : Proses produksi
- rincian_biaya.html         : Rincian biaya
- ringkasan_kalkulasi.html   : Ringkasan kalkulasi

Cara mencoba:
1. Ekstrak seluruh file dari ZIP ke satu folder yang sama.
2. Buka index.html di browser.
3. Gunakan menu di sidebar untuk berpindah halaman.

Catatan:
- Semua halaman harus tetap berada dalam satu folder agar tautan navigasi berfungsi.
- Penyimpanan masih menggunakan localStorage browser, jadi data tiap komputer/browser belum otomatis tersinkron.
- Untuk berbagi data antar komputer kantor, aplikasi perlu dipasang pada web server dan dihubungkan ke database bersama.
